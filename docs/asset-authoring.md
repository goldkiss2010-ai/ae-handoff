# 自分の粒子場を持ち込む

## 書き出す状態

公開用の基本プロファイル`point3-pv`では、全サンプルを通して粒子数と順序を固定します。
各粒子は`x, y, z, vx, vy, vz, visibility, scalar0`の8個のfloat32です。
新規配布素材はsample_rate=1とし、vx・vy・vzは保存サンプル番号qに対する位置の微分です。
保存する間隔を変えた場合、微分もそのq尺度へ換算します。
右手系XYZ・Z-upと、同一ファイル内で統一した長さ単位を使います。

生成言語、計算機、ソルバーは任意です。Pythonの参照実装以外でも、
[固定規約](../core/docs/contract-v1.md)と[バイト配置](../core/docs/format.md)に従って書き出せます。
形状や動きの正しさは生成側の責任です。FLD1への格納自体が物理的な正確さを保証するものではありません。

visibilityで固定スロットの表示・非表示を表せますが、別の粒子へのスロット再利用や
瞬間的な飛び移りはHermite補間で意図しない軌跡になる場合があります。
FLD1 v1には不連続・Holdを指定するフラグがありません。

## アセットに添える説明

| 項目 | 記載する内容 |
|---|---|
| 内容 | 何を生成したか。解析式・数値シミュレーション・画像変換など |
| データ | 粒子数、保存サンプル数、ファイル容量、プロファイル |
| 座標 | 長さ単位・物理的な縮尺、座標系、概略の座標範囲 |
| 進行 | sample_rate=1、位置の微分が保存サンプル番号基準であること |
| 属性 | scalar0の意味・単位。未使用なら0 |
| 再生成 | 生成コード、実行方法、主要パラメータ、乱数seed、依存環境 |
| AE初期設定 | 推奨Samples / Second、Sample Offset、視点・スケールなど |
| 利用条件 | 作者、キャッシュ・コード・入力素材の利用条件 |

これらは付随JSONやREADMEに記載します。JSONの項目は現段階では説明用であり、
AEが自動で読んで再生やカメラを設定する機能はありません。
完成キャッシュの再生と、生成環境での再生成を分けて説明してください。

## 読み込みと見た目の確認

参照ツールで構造・ファイル長を検査し、位置・微分などに非有限値がないことも確認します。
次にAEで先頭・途中・終点を確認し、補間、視点移動、速度に依存する描画を確認します。
参照ツールの構造検査だけでは、全レコードの数値や生成内容の正しさを保証しません。
現在のAEはvisibilityの扱いにモード差があり、scalar0による描画制御には対応していません。

低粒子数版と高粒子数版を用意する場合は、座標範囲と進行を揃え、
差し替えたときの違いを記載します。同一の粒子軌跡や完全な画の一致は自動的には保証されません。
